# BINDU LUXE INTERIORS

Premium multi-page interior design website.

## Pages
1. index.html — Home
2. interior.html — Interior Design
3. gallery.html — Premium Gallery
4. services.html — Services
5. about.html — About Us
6. projects.html — Projects
7. contact.html — Contact & Booking

## Live Server
Open this folder in VS Code and use Live Server on `index.html`.
The frontend forms store demo submissions in browser localStorage.

## Node.js backend
Install Node.js, then run:

npm install
npm start

Open:
http://localhost:3000

The Express backend provides:
POST /api/bookings
POST /api/enquiries
GET /api/health

The included backend stores submissions as JSON files in `data/`.
